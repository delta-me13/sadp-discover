安装位置

  • /Applications/sadp-discover.app：图形界面（通用二进制，Apple Silicon 与 Intel 通用）
  • /usr/local/bin/sadp-discover：命令行版本，与 app 内的可执行文件逐字节相同

首次运行

第一次扫描时系统会请求「本地网络」权限——这是访问局域网广播所必需的，拒绝后需要去 系统设置 → 隐私与安全性 → 本地网络 里重新打开。

卸载

这个包没有卸载器，删掉两个路径即可（详见项目 README）：

sudo rm -rf /Applications/sadp-discover.app /usr/local/bin/sadp-discover
